# DORI Web

Application web de la plateforme DORI, construite avec React, TypeScript et Vite.

## Prérequis

- Node.js 22+
- npm 11+

## Commandes

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

Copier `.env.example` vers `.env.local` pour surcharger l'URL de l'API locale.

Le plan et le suivi détaillé sont disponibles dans `specifications/ai/handover.md`.
